# История версий QuietIsland

Нумерация версий начинается с **1.0.0**. Новые записи добавляются в начало файла.

## 1.2.0 — 2026-11-06

- Плейсхолдеры во всех полях ввода сдвинуты чуть правее текстового курсора, включая поиск, чат, инструменты и настройки.
- Автозагрузка Windows доступна галочкой в установщике и в «Настройки → Общие». Оба переключателя управляют одной записью; обновление учитывает выбор в настройках, отключение и удаление программы убирают автозапуск.

- Рамка выделения подстраивается под окно при наведении, включая его заголовок. Один клик снимает подсвеченное окно; выделение произвольной области завершает снимок сразу при отпускании мыши, без подтверждения.
- Перо, стрелки, рамки, подписи, скрытие области и отмена действий доступны до выбора окна или области. Сначала нанесите дорисовки на экран, затем выберите «Снимок» или нажмите Пробел и захватите окно кликом либо область перетягиванием.
- Готовый снимок автоматически сохраняется в выбранную папку как PNG и копируется в буфер обмена. Отдельное окно редактора после снимка больше не открывается, включая полноэкранный захват.
- Координаты окон и выделения учитывают масштаб интерфейса, перекрытие окон и мониторы слева/сверху от основного; выделение до края сохраняет последнюю строку и колонку пикселей.
- Выпуск содержит оптимизации и небольшие правки интерфейса предыдущей рабочей версии. Маркировка приложения и установщика — 1.2.0; числовая версия Windows — 1.2.0.0.

## 1.1.3 — 2026-11-05

- Размер установки уменьшен: удалены дубли FFmpeg, неиспользуемый FFprobe и установочные зависимости из переносимой папки. Повторная сборка очищает только свой каталог результата, а установщик удаляет старые лишние копии при обновлении.
- Без API ключа ИИ-чат, обработка текста и запрос моделей отключены. Проверка выполняется до чтения вложений и отправки запросов. Сохранённая история остаётся на диске; её карточки не создаются без ключа. HTTP-клиент ИИ создаётся при первом разрешённом запросе и освобождается при выходе.
- Локальный речевой движок Windows по умолчанию выключен. Облачная диктовка требует URL и ключ до доступа к микрофону. Сохранённые настройки пользователя сохраняются при обновлении.
- Превью изображений буфера декодируются в пределах 320×180 пикселей, оригиналы не уменьшаются. Аудиоанализ повторно использует FFT-буферы и заранее вычисленные коэффициенты окна и частотных полос.
- ИИ-запрос сериализуется в поток без дополнительной большой JSON-строки, обновления потокового ответа ограничены частотой 20 раз в секунду.

## 1.1.2 — 2026-11-05

- Автоматическая проверка стабильных выпусков GitHub при запуске и раз в шесть часов, уведомление в трее и раздел «Обновления». Установщик можно скачать с прогрессом, отменить загрузку и запустить из приложения; размер и доступная SHA-256 проверяются перед установкой. Запись экрана и диктовку сначала нужно остановить.
- Запись экрана использует FFmpeg из папки установщика `tools\ffmpeg` до поиска в PATH. Ошибка запуска показывает выбранный файл и код ошибки Windows.
- Пустая полка и свободное место между файлами принимают файлы перетаскиванием по всей площади раздела.
- Напоминания распознают время суток: `9 вечера` — 21:00, `3 дня` — 15:00, `12 ночи` — 00:00. Поддерживаются минуты, «завтра» и повторения; указание времени убирается из названия.

## 1.1.1 — 2026-11-04

- Поиск приложений распознаёт сокращения по начальным буквам слов и частей имени: `vs`, `vsc`, `vb`. Такие совпадения имеют приоритет над случайными фрагментами имени, приложения выводятся перед файлами Everything.
- Скорость ветра запрашивается и отображается в метрах в секунду, с точностью до одного десятичного знака.

## 1.1.0 — 2026-11-04

### Ярлыки

- Кнопка «+» на главной открывает диалог добавления с названием и адресом ярлыка.
- Стандартные ярлыки остаются рядом с пользовательскими. Существующие ярлыки сохраняются при обновлении; стандартные добавляются один раз без дубликатов.
- Правая кнопка на любом ярлыке главной открывает контекстное меню: открыть, изменить название и ссылку, задать группу или горячую клавишу, убрать ярлык.
- Добавление, изменение и удаление сразу обновляют список. Главная и поиск используют общий диалог и действия.

### Таймер

- По окончании таймера чёлка увеличивается и показывает надпись «Таймер».
- Справа доступны две кнопки с иконками: повтор и закрытие, без текста на кнопках.
- Звуковой сигнал повторяется до закрытия, повтора или запуска нового таймера и останавливается при выходе из программы.
- Повтор запускает таймер на исходную длительность.

### Буфер обмена

- История хранится только в текущем сеансе и сбрасывается при перезапуске программы или компьютера, включая закреплённые записи.
- История больше не записывается в `state.json`; ранее сохранённая история не восстанавливается.
- Временные изображения буфера очищаются при следующем запуске. Исходные файлы, полка, заметки и чат сохраняются.

## 1.0.0

Начальная версия приложения, принятая за точку отсчёта истории:

- Чёлка для Windows с часами, музыкой и состоянием раскладки.
- Главная с быстрыми действиями, ярлыками и поиском Everything.
- История буфера, полка файлов, заметки, таймер и напоминания.
- Снимки и запись экрана, распознавание текста, QR-коды и инструменты для текста.
- Погода, чат с ИИ, диктовка, настройки внешнего вида и горячих клавиш.
