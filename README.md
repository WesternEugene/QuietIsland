# QuietIsland

Нативная чёлка для Windows 10/11 x64: поиск Everything, музыка, буфер, файлы, заметки и инструменты

## Установка

Скачайте установочный пакет со [страницы релизов](https://github.com/WesternEugene/QuietIsland/releases)
Установщик включает в себя Everything и FFmpeg

## Использование

Наведите курсором на остров, чтобы раскрыть меню

Чтобы открыть поиск нажмите сочетание **Alt + Пробел**. Если это сочетание клавиш занято, то используется **Ctrl + Alt + Пробел**

В верхней панели восемь основных разделов: главная, буфер, полка, текст, чат, заметки, погода и управление. Поиск также открывается кнопкой «Команда» на главной

| Сочетание | Действие |
|---|---|
| Ctrl + Alt + V | Буфер обмена |
| Ctrl + Alt + N | Заметки, таймер, напоминания |
| Ctrl + Print Screen | Снимок области с разметкой |
| Ctrl + Alt + R | Выбрать область записи / остановить запись |
| Ctrl + Alt + D | Начать / закончить диктовку |
| Ctrl + Enter в поиске | Показать выбранный файл в папке |
| Ctrl + Shift + Enter в поиске | Запустить выбранную программу от имени администратора |
| Ctrl + Enter в чате | Отправить сообщение |

## Примеры команд

`таймер 10 мин`, `напомни таблетки каждый день в 23:00`, `напомни через 20 минут выключить плиту`, `2 + 3 * 4`, `10 см в дюймы`, `2 кг в фунты`, `100 градусов Фаренгейта в Цельсия`, `1 inch to cm`, `100 USD to RUB`, `happ`, `? объясни этот код`, `web погода завтра`. Русские единицы распознаются со склонениями и десятичной запятой. Строка после `>` запускается в отдельном окне cmd **только по Enter**.

Ярлыки добавляются кнопкой «+ Ярлык». Поддерживаются пути, сайты и ссылки вида `steam://run/…`. Перетащите ярлык на другой, чтобы создать группу; контекстное меню меняет ссылку, группу и клавишу. Изменения клавиш применяются сразу.

## Хранение

`%LOCALAPPDATA%\QuietIsland` — `state.json`, резервная копия, изображения буфера, вложения чата и файл токена моста. Ключи и пароль OBS защищены DPAPI текущего пользователя Windows. Буфер, заметки и история чата не шифруются целиком. Ключи и содержимое сообщений не записываются в журнал ошибок

Полка хранит ссылки на исходные файлы. Двойной щелчок / Enter открывает файл. Правая кнопка: открыть, показать в папке, скопировать файл или путь, убрать с полки. Перетаскивание начинается после обычного порога движения; можно перетаскивать все файлы верхней кнопкой. Delete убирает выбранную ссылку с полки. Удаление записи не удаляет оригинал. Незакреплённая история буфера ограничена настройкой; закреплённые записи сохраняются. Буфер пропускается, когда на переднем плане распознаётся KeePass/Bitwarden/1Password/Keeper.

## Сборка и проверки

```powershell
.\build.ps1 -Diagnose
```

SDK загружается с официального сайта Microsoft в `.tools\dotnet`, если .NET 10 SDK отсутствует. Скрипт запускает .NET-тесты и тесты Node, собирает переносимый выпуск и, с `-Diagnose`, запускает нативные проверки Everything, OCR, QR, моста и протокола ИИ. Для сборки без встроенной среды: `./build.ps1 -SelfContained $false`.
